# 🎮 KaZe Mods Hub

Plateforme moderne, responsive et optimisée de partage de mods Minecraft.

## 🚀 Fonctionnalités
- **Performance & PWA**: Installation sur mobile/PC & support Offline basic via Service Worker.
- **Base de Données Dynamique**: Connexion Firebase Firestore v10.
- **Panneau Admin complet**: Authentification Firebase Auth, upload Firebase Storage, CRUD complet.
- **Moteur de Recherche & Filtres**: Recherche instantanée instant-filter, par catégorie et par tags.

## 🛠️ Déploiement sur GitHub Pages

1. Créez un nouveau dépôt sur GitHub nommé `kaze-mods-hub`.
2. Clonez le projet et poussez tous les fichiers.
3. Configurez vos clés dans `firebase.js`.
4. Créez un compte Administrateur via l'onglet **Authentication** de la console Firebase.
5. Sur GitHub, rendez-vous dans `Settings` > `Pages`.
6. Sélectionnez la branche `main` et enregistrez.
